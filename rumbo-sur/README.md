## Estructura
- `/docs` – documento de análisis y diseño (Etapa 1) en PDF
- `/docs/uml` – diagramas UML: fuente `.puml` (PlantUML) e imagen `.png`


## Regenerar los diagramas
```
java -jar plantuml.jar -charset UTF-8 docs/uml/*.puml
```

## Requisitos
Java 17 o superior. Instrucciones de ejecución: se completan en la Etapa 2.
